Local AI on your 16 GB Mac with Ollama: 5.3 GB for an 8B model

  1. measure.sh asks the local Ollama server to load one model, at a context size you choose.
  2. The server starts a model runner, which takes its share of the Mac's unified memory.
  3. Then it reads ollama ps, the runner's resident memory, memory pressure and swap, and stops at the first context that no longer fits on the GPU.
